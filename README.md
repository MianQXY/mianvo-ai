# Mianvo — AI Video, Image & Audio Creation

[Mianvo](https://mianvo.com/) brings AI video, image and audio tools into one browser workspace. Start with an idea or supported reference files, choose a tool and model, review the credit quote, and preview your results.

This repository collects a product overview and practical starting points for using the Mianvo web app.

**[Open Mianvo](https://mianvo.com/) · [Browse tools](https://mianvo.com/tools) · [Read the docs](https://mianvo.com/docs)**

## What you can create

| Task | Starting point | What to prepare |
| --- | --- | --- |
| Generate a video from an idea | [Text to Video](https://mianvo.com/text-to-video) | A subject, an action and a scene description |
| Animate a still image | [Image to Video](https://mianvo.com/image-to-video) | A reference image and a description of motion |
| Explore a visual concept | [Text to Image](https://mianvo.com/text-to-image) | A description of the subject, composition and lighting |
| Refine an existing image | [AI Image Editor](https://mianvo.com/image-to-image) | An image and a specific edit request |
| Explore a music idea | [AI Song Generator](https://mianvo.com/ai-song-generator) | A musical direction, with lyrics or references where supported |
| Create spoken audio | [Text to Speech](https://mianvo.com/text-to-speech) | A script and an available voice |

Inputs, supported controls and output specifications depend on the selected tool and model. Check the live form before preparing your files.

## A practical workflow

1. **Choose the result first.** Decide whether you need a video, an image or audio, then select the matching tool.
2. **Prepare the required inputs.** Check accepted formats and upload requirements. Some models need only text; others require reference files.
3. **Choose a model and review its settings.** Duration, aspect ratio, resolution and output quantity are available only where supported.
4. **Check the credit quote.** Review it again after changing a model, input or setting.
5. **Generate, preview and download.** Check an existing task's status before starting another request if processing seems delayed.

Creations are private by default. You can choose which completed results to publish; publishing a result does not publish your original uploaded files.

## Prompt starting points

These are original example prompts to adapt to your subject and selected model, rather than promises of a particular output.

### Product image to video

Upload a product photo, then begin with one motion and a clear camera direction:

```text
A slow camera move toward the product on the tabletop. Soft window light
from the left, a calm background, and a subtle shift in the reflections.
```

Start with a restrained motion request. Review the product's shape, markings and background in the generated clip before using it.

### Image concept

```text
A ceramic cup on a wooden desk beside a window, warm morning light,
eye-level composition, soft background, natural colors.
```

Adjust the subject, setting and composition for your project. Use reference inputs only where the selected model supports them.

### Instrumental direction

```text
A mellow instrumental with soft keys, a relaxed drum groove and a warm
evening mood. No vocals.
```

Use the instrumental controls provided by the selected audio model when available, then listen to the result before downloading it.
